# بازی پینگ‌پونگ (Pong)

یک بازی دوبعدی جذاب ساخته‌شده با زبان برنامه‌نویسی Rust.


# ویژگی‌ها

* **حالت‌های متنوع بازی:** امکان بازی ۲ نفره یا رقابت با هوش مصنوعی (آسان و سخت)
* **سیستم پاورآپ‌ها:** شامل بزرگ/کوچک شدن راکت، انجماد حریف، کلیدهای معکوس، سپر و توپ اضافه
* **طراحی بصری:** محیط گرافیکی جذاب همراه با منوهای اختصاصی و شمارش معکوس
* **توسعه با Rust:** استفاده از موتور Bevy، عملکرد بالا و مدیریت امن حافظه
